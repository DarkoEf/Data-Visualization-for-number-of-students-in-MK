Семинарска по предметот Дизајн на итеркација човек компјутер

Во апликацијата се дава визуелизација на бројот на студенти кои ги посетуваат факултетите во Македонија.
Факултетите и бројот на студенти се преземени од Државен завод за статистика од официјалната веб страна https://www.stat.gov.mk/prikazisoopstenie.aspx?rbrtxt=29.
Факултетите и бројот на студенти се внесуваат при отварање на апликацијата при што се прикажуваат на дијаграмот(столбест), може да се смене во index.html ако сакаме: line, pie или друго.
